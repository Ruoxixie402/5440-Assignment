# Data provenance

The supplied `marks.txt` contains 100 rows of two numeric exam scores and a binary admission label, with no names or other identity fields. Its numerical contents were checked against the public `ex2data1.txt` example and match exactly:

https://github.com/Benlau93/Machine-Learning-by-Andrew-Ng-in-Python/blob/master/LogisticRegression/ex2data1.txt

The notebook, Python source, PDF, and plots are generated solutions and results for that example. The corrected notebook metadata contain only the Python kernel and language information. The generated text files contain no personal home-directory paths or email addresses. Neither the original uploaded notebook nor lecture PDFs are included in this repository.

The reference-notebook header convention is documented in the README and solution: reading the headerless file with pandas' default header inference leaves 99 observations.
